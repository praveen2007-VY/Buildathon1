# Changelog

All notable changes to the EduAI Education Management Portal will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-16

### Added
- Initial release of EduAI Education Management Portal platform.
- Role-based dashboards for Students, Teachers, and Administrators with protected routes and custom layouts.
- Course catalog management, enrollment, class schedule tracking, and user profile updates.
- Assignment creation, file submission, teacher evaluation, and automated feedback generation.
- Attendance recording, student summary calculations, and subject-level breakdowns.
- Interactive quiz and exam engine with score tracking and submission capabilities.
- Grade management system with GPA computation, semester tracking, and transcript recording.
- AI Academic Intelligence service layer providing student performance recommendations, teacher weak-topic insights, and institutional academic risk analytics.
- Backend server built with Express and TypeScript, utilizing JWT authentication, bcrypt password hashing, and custom JSON file persistence.
- Comprehensive repository documentation, architecture diagrams, technology matrix, API reference, and setup guide in `README.md`.
